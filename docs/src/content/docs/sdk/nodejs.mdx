The Node.js / TypeScript SDK (`monosecret`) is a thin wrapper over a
[napi-rs](https://napi.rs/) native addon that embeds the resolver. Resolution
happens in the Rust core, so the SDK inherits every provider with no JS-side
logic. npm installs a prebuilt addon for the host platform: Linux x64 and
arm64 (glibc, and musl for Alpine images in 0.3+), macOS on Apple silicon, and
Windows x64. TypeScript declarations ship in `index.d.ts`.

## Caller context {/* #caller-context-020 */}

:::note[Version compatibility]
Added in Monosecret 0.3.
:::

```js
const builder = Monosecret.builder().withCaller({
  name: 'git',
  version: '2.51.0',
  operation: 'credential_get',
  resource: 'github.com',
});
```

Caller context identifies the invoking integration in audit records but never
satisfies `require_reason`. Do not put credentials or secret values in it.

## Inline specifications {/* #inline-specifications-020 */}

:::note[Version compatibility]
Added in Monosecret 0.3.
:::

Use `.withInlineSpec(spec, baseDir)` (or `loadAsync`/`reportAsync`) to resolve a
strict inline-spec v2 object (Monosecret 0.4.0+). `baseDir` resolves relative
provider paths; the embedded addon submits the versioned native request directly.

## Typed access (codegen)

Generate typed interfaces with `monosecret schema` plus
[quicktype](https://quicktype.io), then convert `resolved.fieldsJson()`:

```bash
$ monosecret schema | quicktype -s schema --top-level Monosecret --lang typescript -o secrets_gen.ts
```
